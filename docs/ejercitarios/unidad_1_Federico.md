## Tema 1 · Ingeniería de software: una visión previa

**1. En tus propias palabras, define qué es la Ingeniería de Software.**

_Respuesta:_
Es la disciplina que aplica principios, métodos y buenas prácticas de la ingeniería al desarrollo de software, con el objetivo de crear sistemas confiables, eficientes y mantenibles.

**2. Explica con un ejemplo la diferencia entre "programar" y "hacer ingeniería de software".**

_Respuesta:_
Programar es escribir código para resolver un problema puntual, por ejemplo, hacer un script que calcule promedios. Hacer ingeniería de software implica diseñar, planificar y mantener un sistema completo, como una aplicación de gestión escolar, considerando requisitos, arquitectura, pruebas y mantenimiento.

**3. Menciona dos razones por las cuales la ingeniería de software es necesaria en el desarrollo de sistemas actuales.**

_Respuesta:_
Los sistemas modernos son complejos y requieren organización para evitar errores y sobrecostos.

Permite garantizar calidad, seguridad y escalabilidad en aplicaciones que usan millones de personas.

## Tema 2 · El rol de la IS en el diseño de sistemas (+ impacto de la IA)

**4. Enumera los elementos que conforman un sistema basado en computadora, además del software.**

_Respuesta:_
Hardware, datos, usuarios, procedimientos y redes de comunicación.

**5. Describe brevemente la diferencia entre una visión sistémica y una visión aislada del software en el diseño de sistemas.**

_Respuesta:_
La visión sistémica considera el software como parte de un conjunto integrado con hardware, usuarios y procesos. La visión aislada lo analiza de forma independiente, sin contemplar su interacción con otros elementos.

**6. Elige una herramienta de inteligencia artificial aplicada al desarrollo de software (por ejemplo, un asistente de código o de testing) e indica:**
- Qué tarea del ingeniero de software apoya o transforma.
- Un beneficio concreto que ofrece.
- Un riesgo o desafío que introduce su uso.

_Respuesta:_
Herramienta: Asistente de código (ej. GitHub Copilot).

Tarea: Apoya al ingeniero sugiriendo fragmentos de código y acelerando la programación.

Beneficio: Aumenta la productividad y reduce errores comunes.

Riesgo: Puede generar código inseguro o poco optimizado si no se revisa críticament

## Tema 3 · Historia de la ingeniería de software

**7. En tu opinión, ¿por qué la "crisis del software" de 1968 marcó un punto de inflexión para la disciplina?**

_Respuesta:_
Porque evidenció que los métodos informales no eran suficientes para proyectos grandes; se necesitaban procesos estructurados, lo que dio origen a la ingeniería de software como disciplina formal.

## Tema 4 · El rol del ingeniero de software

**8. Menciona tres competencias que debe tener un ingeniero de software, además del conocimiento técnico.**

_Respuesta:_
Comunicación efectiva, trabajo en equipo y pensamiento crítico para la resolución de problemas.

**9. Describe brevemente qué hace cada uno de los siguientes roles dentro de un equipo de desarrollo:**

| Rol | Descripción |
|---|---|
| Analista | Recoge y define requisitos, traduce necesidades del cliente en especificaciones técnicas. |
| Arquitecto |Diseña la estructura del sistema y toma decisiones sobre tecnologías y patrones.  |
| Desarrollador | Implementa el código siguiendo las especificaciones y buenas prácticas. |
| Tester / QA | Verifica la calidad del software mediante pruebas y asegura que cumpla los requisitos. |

**10. Caso breve:** Un ingeniero de software descubre, cerca de la fecha de entrega, una falla de seguridad que podría exponer datos de usuarios, pero corregirla retrasaría el proyecto una semana. ¿Qué debería hacer y por qué, considerando la ética profesional?

_Respuesta:_
Debe corregir la falla de seguridad aunque retrase la entrega, porque la ética profesional prioriza la protección de los datos de los usuarios sobre la presión de cumplir plazos.

Pruebas

Mantenimiento

**12. ¿Por qué se afirma que el mantenimiento suele ser la fase más costosa del ciclo de vida del software? Da un ejemplo hipotético.**

_Respuesta:_
Porque implica corregir errores, actualizar funcionalidades y adaptarse a nuevas tecnologías. Ejemplo: un sistema bancario que debe actualizarse constantemente para cumplir nuevas regulaciones y soportar más usuarios.

## Tema 7 · Relación con otras disciplinas

**13. Elige dos de las siguientes disciplinas — Administración, Psicología, Economía, Derecho, Comunicación — y explica con un ejemplo concreto cómo se relacionan con el trabajo diario de un ingeniero de software.**

_Respuesta:_
Administración: Un ingeniero debe gestionar proyectos, plazos y recursos. Ejemplo: aplicar metodologías de gestión para coordinar equipos.

Psicología: Ayuda a comprender la experiencia del usuario y diseñar interfaces más intuitivas. Ejemplo: aplicar principios de usabilidad en una aplicación móvil.

_Respuesta:_
La idea más relevante es que la ingeniería de software no se limita a programar, sino que integra procesos, personas y tecnologías para garantizar calidad y seguridad en sistemas que impactan directamente en la vida diaria.
